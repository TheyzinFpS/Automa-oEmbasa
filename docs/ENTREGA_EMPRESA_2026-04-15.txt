12. COMO RODAR NO PC DA EMPRESA

12.1 Modo mais simples - executavel
- Abrir:
  `dist/EMBASA/EMBASA.exe`
- Esse modo nao exige terminal para uso operacional.

12.2 Modo desenvolvimento - via terminal
Pre-requisitos esperados no PC da empresa:
- Python 3.11 instalado
- SAP GUI instalado
- SAP GUI Scripting habilitado
- Edge WebView2 / Edge Chromium disponivel

Se ainda nao existir ambiente virtual no projeto:
- Abrir PowerShell na raiz do projeto
- Executar:
  `powershell -ExecutionPolicy Bypass -File .\setup_env.ps1`

Se o ambiente virtual ja existir:
- Ativar:
  `.\.venv\Scripts\Activate.ps1`

Rodar a interface em modo codigo:
- Opcao recomendada:
  `.\.venv\Scripts\python.exe .\main.py`
- Opcao alternativa, se o Python 3.11 correto estiver no PATH:
  `python .\main.py`

13. COMO REBUILDAR O EXECUTAVEL
- Na raiz do projeto, executar:
  `powershell -ExecutionPolicy Bypass -File .\build_exe.ps1`
- Saida esperada:
  `dist/EMBASA/EMBASA.exe`
